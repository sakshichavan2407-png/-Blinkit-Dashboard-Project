# Blinkit Grocery Sales Dashboard (Excel)

An interactive Excel dashboard that analyses Blinkit grocery sales data across items, outlets and locations, built with pivot tables, charts and slicers.

## Project Overview
The goal of this project is to turn raw grocery sales data into clear, actionable insights. The dashboard helps answer questions such as which product categories drive the most sales, which outlet types and locations perform best, and how customer ratings compare across outlets.

## Key Metrics (KPIs)
- **Total Sales:** ~1.20M
- **Average Sales per Item:** ~141
- **Number of Items:** 8,523
- **Average Rating:** 3.92

## Dashboard Visuals
- Total sales by item fat content
- Sales by fat content across outlet location tiers
- Total sales by item type
- Sales by outlet establishment year
- Sales by outlet size
- Sales by outlet location type
- Sales, average sales and item count by outlet type
- Interactive slicers for filtering the dashboard

## Key Insights
- **Low Fat items** generate about 65% of total sales (~776K vs ~425K for Regular).
- **Fruits and Vegetables** and **Snack Foods** are the top-selling categories, together contributing about 30% of sales.
- **Tier 3** locations lead in sales, followed by Tier 2 and Tier 1.
- **Medium-sized** outlets contribute the most sales, followed by Small and High.
- **Supermarket Type 1** accounts for roughly 65% of total sales.
- Outlets established in **2018** show the highest sales.
- Average ratings are consistent (~3.9) across all outlet types.
